## 六经辨证

六经辨证出自张仲景《伤寒论》，是外感病（风寒类）的辨证纲领。它以阴阳为总纲，按病位、病性、病势把外感病分为 **太阳、阳明、少阳、太阴、少阴、厥阴** 六类，用来判断邪正盛衰、病变层次与传变趋势，并据此确定治法与方剂。

三阳病（太阳、阳明、少阳）多属邪盛而正未衰，以六腑病变为基础，病势亢盛；三阴病（太阴、少阴、厥阴）多属正气已衰，以五脏病变为基础，病势虚弱。

### 六经提纲与主症

| 六经 | 病位 / 病性 | 提纲与主症 | 常见证型 | 代表方 |
|---|---|---|---|---|
| 太阳 | 表证（表寒） | 「脉浮，头项强痛而恶寒」 | 中风（表虚：汗出恶风，脉浮缓）；伤寒（表实：无汗而喘，脉浮紧）；蓄水；蓄血 | 桂枝汤、麻黄汤、五苓散、桃核承气汤 |
| 阳明 | 里证，实热 | 「胃家实」；身热汗出，不恶寒反恶热 | 经证（大热、大汗、大渴、脉洪大）；腑证（痞、满、燥、实） | 白虎汤、承气汤类 |
| 少阳 | 半表半里 | 「口苦、咽干、目眩」；往来寒热、胸胁苦满、默默不欲饮食、心烦喜呕，脉弦 | 少阳本病；少阳兼阳明 | 小柴胡汤、大柴胡汤 |
| 太阴 | 里证，脾胃虚寒 | 「腹满而吐，食不下，自利益甚，时腹自痛」 | 脾胃虚寒、寒湿内聚 | 理中丸（汤） |
| 少阴 | 里证，心肾虚衰（危重） | 「脉微细，但欲寐」 | 寒化（无热恶寒、四肢厥冷、下利清谷、脉微欲绝）；热化（心烦不寐、舌红、脉细数） | 四逆汤、黄连阿胶汤 |
| 厥阴 | 里证，寒热错杂 | 「消渴，气上撞心，心中疼热，饥而不欲食，食则吐蛔」 | 上热下寒、寒热错杂 | 乌梅丸 |

### 传变

- **循经传**：太阳 → 阳明 → 少阳 → 太阴 → 少阴 → 厥阴。
- **越经传**：跳过一经或数经而传，多因邪盛正虚。
- **表里传**：如太阳传少阴，由实转虚，多示病进。
- **直中**：起病即见三阴证，不经三阳。
- **合病、并病**：两经或三经同时发病为合病；一经未罢又传一经为并病。
- **阴病转阳**：正气渐复，为向愈之象。

传变与否取决于体质强弱、感邪轻重与治疗当否；临证以证候变化为据，不可拘泥日数。

### 辨证思路

1. **先分阴阳**：三阳多实热，三阴多虚寒。
2. **再定病位**：表（太阳）、里（阳明与三阴）、半表半里（少阳）。
3. **细辨寒热虚实**：注意真寒假热、真热假寒，脉之有力无力、舌之胖嫩苍老可作鉴别。
4. **抓主症、参舌脉**：定六经证型，再依法选方。
5. **动态观察**：留意传变与合病并病，随证治之。

### 学习提示

- 六经辨证主要用于外感风寒类疾病；温热病用卫气营血、三焦辨证，内伤杂病以脏腑辨证为主，八纲为一切辨证的总纲。
- 条文与方证以《伤寒论》原文为据，本仓库仅作学习整理；方药与剂量须由执业中医师面诊确定，不构成诊疗建议。

# 中文论文：中西医结合、中医、中医 + AI

本目录列出 8 篇中文论文，均可在《中草药》官网**免费阅读和下载**，覆盖三个方向：

- **中西医结合**（2 篇）：临床诊疗指南 + 中西医结合综述；
- **中医**（2 篇）：中医证候/病证结合的模型与临床研究；
- **中医 + AI**（4 篇）：大语言模型、经典名方研发、名医智能体、AI + 类器官。

## 为什么 PDF 没有直接放进仓库

这些论文可以在期刊官网免费下载，但《中草药》保留版权，未采用 CC BY 等开放许可。本仓库是公开仓库，直接再分发 PDF 可能超出合理使用范围，因此这里只保留**元数据、官网链接和下载脚本**；需要全文时在本地运行脚本即可。

## 一键下载

```bash
python3 scripts/download_chinese_papers.py
```

## 怎么读

- **01、02** 看中文“中西医结合”怎么写：指南体例、证据分级、中西医术语对照；
- **03、04** 看中医证候如何做动物模型与临床关联，尤其是“证候—指标—疗效”的证据链；
- **05–08** 看中医 + AI 的四条路线：LLM 基础设施、经典名方研发、临床智能体、AI + 类器官实验平台；
- 读的时候对照英文 AI 论文（`papers/12`–`14`），比较中英文期刊在方法、验证与报告规范上的差异。
